### 效果：UV 滚动 2D 背景板

**视觉本质：**

同一个面片不断从贴图的不同位置取颜色。

**输入数据：**

```text
_MainTex      第一层背景图
_DetailTex    第二层背景图
_ScrollX      第一层横向滚动速度
_Scroll2X     第二层横向滚动速度
_Multiplier   最终颜色亮度倍增
```

**输出数据：**

```text
positionCS    裁剪空间坐标，用来把模型绘制到屏幕
uv.xy         第一层背景滚动后的 UV
uv.zw         第二层背景滚动后的 UV
```

**处理流程：**

1. 计算第一层和第二层背景滚动后的 UV。
2. 在片元阶段分别采样两层贴图。
3. 使用第二层贴图的 Alpha 混合两层颜色。
4. 使用 `_Multiplier` 对最终颜色进行亮度倍增。

**输出：**

```hlsl
return color;
```

得到两层贴图以不同速度横向滚动并进行 Alpha 混合的 2D 背景。

**依赖：**

```hlsl
#include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"
```

**Render State：**

```shaderlab
"RenderType" = "Opaque"
"RenderPipeline" = "UniversalPipeline"
"Queue" = "Geometry"
```

### 效果：基于 Sobel 算子的屏幕空间边缘检测

**视觉本质：**

比较当前像素周围 3×3 区域的亮度变化，把变化明显的位置替换为边缘颜色，并在“原图叠加边缘”和“纯色背景边缘图”之间混合。

**输入数据：**

```text
_BlitTexture             RenderGraph Blit 传入的当前相机颜色纹理
_BlitTexture_TexelSize   _BlitTexture 单个纹素对应的 UV 尺寸，xy 为 1/宽度、1/高度
_EdgeOnly                原图边缘模式与纯边缘模式的混合比例
_EdgeColor               检测到的边缘所使用的颜色
_BackgroundColor         纯边缘模式下非边缘区域所使用的背景颜色
```

**输出数据：**

```text
positionCS         全屏三角形顶点的裁剪空间坐标，用于覆盖当前颜色目标
texcoord           当前片元对应的屏幕纹理 UV，用于采样相机颜色纹理
edge               反转后的边缘结果：0 表示边缘，1 表示非边缘
sourceWithEdges    保留原图并将边缘替换为 _EdgeColor 的颜色
edgesOnly          使用 _EdgeColor 和 _BackgroundColor 组成的纯边缘图
```

**处理流程：**

1. `Vert` 生成覆盖颜色目标的全屏三角形，并输出屏幕纹理 UV。
2. 以当前 UV 为中心，使用 `_BlitTexture_TexelSize.xy` 定位周围 3×3 共 9 个纹素。
3. 将每个采样颜色转换为亮度，分别与 Sobel 的 `Gx`、`Gy` 卷积核累加，得到水平和垂直亮度梯度。
4. 使用 `saturate(1 - abs(edgeX) - abs(edgeY))` 得到反转后的边缘结果，其中 0 表示边缘、1 表示非边缘。
5. 使用边缘结果分别生成“原图叠加边缘”和“纯色背景边缘图”。
6. 使用 `_EdgeOnly` 在两种结果之间混合，并由 Shader Pass 0 写入 RenderGraph 临时纹理。
7. Shader Pass 1 不再处理颜色，只把临时纹理复制回当前相机颜色纹理。

**输出：**

```hlsl
return lerp(sourceWithEdges, edgesOnly, saturate(_EdgeOnly));
```

`_EdgeOnly` 为 0 时输出保留原图的彩色画面并叠加边缘；为 1 时输出由边缘颜色和背景颜色组成的纯边缘图；介于 0 和 1 时在两种结果之间插值。

**依赖：**

```hlsl
#include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"
#include "Packages/com.unity.render-pipelines.core/Runtime/Utilities/Blit.hlsl"
```

**Render State：**

```shaderlab
"RenderType" = "Opaque"
"RenderPipeline" = "UniversalPipeline"

ZTest Always
ZWrite Off
Cull Off

Pass 0: Name "EdgeDetection"
Pass 1: Name "Copy"
```

### 效果：Bloom 辉光后处理

**视觉本质：**

提取画面中亮度超过阈值的区域，对其进行多次降采样高斯模糊，最后通过硬件加法混合叠加回原图，使亮部产生向外扩散的柔和光晕。

**输入数据：**

```text
_BlitTexture             RenderGraph Blit 传入的当前源纹理（Extract 阶段为相机颜色，模糊阶段为上一步输出）
_BlitTexture_TexelSize   源纹理单个纹素对应的 UV 尺寸
_BlurSpread              高斯模糊采样偏移的倍增系数
_LuminanceThreshlod      亮度提取阈值，低于此值的像素被过滤
```

**输出数据：**

```text
tempA / tempB            降采样临时纹理，在模糊迭代中乒乓交替使用
srcCamColor              最终叠加 bloom 光晕后的相机颜色纹理
```

**处理流程：**

1. Pass 0（ExtractBright）：采样原图，计算感知亮度并减去阈值，将低于阈值的像素置零，输出到降采样临时纹理 tempA。
2. Pass 1-2 循环 iterations 次（Vertical + Horizontal）：在 tempA 和 tempB 之间乒乓交替执行 5-Tap 高斯模糊，每次迭代累积扩散范围。
3. Pass 3（Combine）：以 Blend One One 加法混合模式，将模糊后的 tempA 叠加到 srcCamColor 上，实现 scene + bloom 效果。

**输出：**

```hlsl
return SAMPLE_TEXTURE2D_X_LOD(_BlitTexture, sampler_LinearClamp, input.texcoord, _BlitMipLevel);
```

Combine Pass 输出模糊后的亮部颜色，由 `Blend One One` 硬件混合叠加到已有的场景颜色上，产生发光物周围柔和扩散的辉光效果。

**依赖：**

```hlsl
#include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"
#include "Packages/com.unity.render-pipelines.core/Runtime/Utilities/Blit.hlsl"
```

**Render State：**

```shaderlab
"RenderType" = "Opaque"
"RenderPipeline" = "UniversalPipeline"

ZTest Always
ZWrite Off
Cull Off

Pass 0: Name "BLOOM_EXTRACT_BRIGHT"
Pass 1: Name "BLOOM_BLUR_VERTICAL"
Pass 2: Name "BLOOM_BLUR_FragHorizontal"
Pass 3: Name "BLOOM_COMBINE"  Blend One One

### 效果：高斯模糊后处理

**视觉本质：**

利用一维高斯分布权重，在垂直和水平两个方向上分别对邻域像素进行加权平均，使相邻像素颜色融合，实现画面的平滑模糊效果。

**输入数据：**

```text
_BlitTexture             RenderGraph Blit 传入的源纹理（纵向为相机颜色，横向为临时模糊纹理）
_BlitTexture_TexelSize   源纹理单个纹素对应的 UV 尺寸
_BlurSpread              高斯模糊采样偏移的倍增系数
```

**输出数据：**

```text
positionCS               全屏四边形顶点的裁剪空间坐标
texcoord                 当前片元的屏幕纹理坐标，用于采样
```

**处理流程：**

1. 顶点阶段：使用 `Blit.hlsl` 内置的 `Vert` 顶点着色器生成全屏四边形并输出屏幕 UV。
2. 片元阶段 - 纵向 Pass（Pass 0）：以当前 `texcoord` 为中心，在垂直方向 `float2(0.0, 1.0)` 上偏移采样 5 个点，按高斯权重加权累加，输出到临时纹理 `dst`。
3. 片元阶段 - 横向 Pass（Pass 1）：以当前 `texcoord` 为中心，在水平方向 `float2(1.0, 0.0)` 上偏移采样 5 个点，按高斯权重加权累加，输出回相机目标。

**输出：**

```hlsl
return SampleGaussianBlur(input.texcoord, float2(0.0, 1.0)); // 纵向
return SampleGaussianBlur(input.texcoord, float2(1.0, 0.0)); // 横向
```

纵向 Pass 输出垂直模糊的过渡图像，横向 Pass 输出水平模糊的最终高斯模糊画面。

**依赖：**

```hlsl
#include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"
#include "Packages/com.unity.render-pipelines.core/Runtime/Utilities/Blit.hlsl"
```

**Render State：**

```shaderlab
"RenderType" = "Opaque"
"RenderPipeline" = "UniversalPipeline"

ZTest Always
ZWrite Off
Cull Off

Pass 0: Name "GAUSSIAN_BLUR_VERTICAL"
Pass 1: Name "GAUSSIAN_BLUR_HORIZONTAL"
```
