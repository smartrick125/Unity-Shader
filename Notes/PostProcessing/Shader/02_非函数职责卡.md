# 02_非函数职责卡

本文件只用于保存具体的 Shader 非函数对象职责记录，不定义模板。

非函数对象包括变量、常量、结构体、字段、语义、属性、关键字、Pass、Tag、Render State 及其他不属于函数且不属于宏的 Shader 元素。宏必须单独记录到 `03_宏卡.md`。

新增记录前必须读取并使用 `.codex-rules/02_Shader知识总结规范.md` 中的“非函数职责卡固定模板”。只有用户主动提出记录某个 Shader 非函数对象时，才在本文件末尾追加记录。

## 非函数记录

### 具体非函数名：

`_CameraOpaqueTexture_TexelSize`

**在哪个效果中记录：**

玻璃折射 + 反射

**形式：**

```hlsl
float4(1 / width, 1 / height, width, height)
```

- `x = 1 / 纹理宽度`
- `y = 1 / 纹理高度`
- `z = 纹理宽度`
- `w = 纹理高度`

**作用：**

把“像素级别的扭曲强度”转换成“UV 级别的偏移量”。

**所在层级：**

```hlsl
#include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/DeclareOpaqueTexture.hlsl"
```

**常见坑：**

`_CameraOpaqueTexture_TexelSize.xy` 是倒数尺寸，不是宽高。

### 具体非函数名：

`_BlitTexture_TexelSize`

**在哪个效果中记录：**

URP RenderGraph 高斯模糊

**形式：**

```hlsl
uniform float4 _BlitTexture_TexelSize;
```

- `x = 1 / _BlitTexture 的宽度`
- `y = 1 / _BlitTexture 的高度`
- `z = _BlitTexture 的宽度`
- `w = _BlitTexture 的高度`

**作用：**

提供源纹理一个纹素所占的 UV 大小。高斯模糊使用
`_BlitTexture_TexelSize.xy * direction * _BlurSpread`
把采样方向和像素间距转换成 UV 偏移量。

**所在层级：**

```hlsl
#include "Packages/com.unity.render-pipelines.core/Runtime/Utilities/Blit.hlsl"
```

**常见坑：**

它是 Unity 根据 `_BlitTexture` 提供数值的 `uniform float4` 变量，不是宏；`.xy` 是宽高的倒数，`.zw` 才是宽高。

### 具体非函数名：

`HLSLINCLUDE / ENDHLSL`

**在哪个效果中记录：**

Bloom 辉光后处理

**形式：**

```shaderlab
HLSLINCLUDE
    // 共享的 HLSL 代码
ENDHLSL
```

ShaderLab 关键字对，用于在 SubShader 级别声明共享的 HLSL 代码块。

**作用：**

`HLSLINCLUDE` 中的代码会被自动插入到同一 SubShader 下每个 Pass 的 `HLSLPROGRAM / ENDHLSL` 块中，避免在多个 Pass 之间重复声明相同的 include、纹理、采样器、CBUFFER 和辅助函数。

**所在层级：**

ShaderLab SubShader 级别，位于 `SubShader { }` 内、各 `Pass { }` 外。

**常见坑：**

- `HLSLINCLUDE` 不是 Pass，不能在其中写 `#pragma vertex/fragment`；`#pragma` 指令必须写在各 Pass 的 `HLSLPROGRAM` 中。
- 它与 `HLSLPROGRAM / ENDHLSL` 是两套不同的配对：前者是共享代码注入，后者是单个 Pass 的编译程序块。
- 旧版 CG 对应的是 `CGINCLUDE / ENDCG`，不能混用。

### 具体非函数名：

`HLSLPROGRAM / ENDHLSL`

**在哪个效果中记录：**

Bloom 辉光后处理

**形式：**

```shaderlab
Pass
{
    HLSLPROGRAM
    #pragma vertex Vert
    #pragma fragment FragExtractBright
    ENDHLSL
}
```

ShaderLab 关键字对，在单个 Pass 内标记需要编译的 HLSL 着色器程序。

**作用：**

定义该 Pass 实际使用的顶点和片元着色器入口点，并触发 HLSL 编译。`HLSLINCLUDE` 中的共享代码会在编译时自动注入到此块的开头。

**所在层级：**

ShaderLab Pass 内部。

**常见坑：**

- 结束标记是 `ENDHLSL` 而非 `ENDHLSLPROGRAM`。
- 旧版 CG 对应的是 `CGPROGRAM / ENDCG`，不能混用。
- 如果 `HLSLINCLUDE` 中已经 include 了某个文件，`HLSLPROGRAM` 中不要重复 include 同一文件。

### 具体非函数名：

`Blend One One`

**在哪个效果中记录：**

Bloom 辉光后处理

**形式：**

```shaderlab
Blend One One
```

ShaderLab 混合状态指令，设置源因子和目标因子均为 `One`。

**作用：**

最终像素颜色 = 片元输出 × 1 + 渲染目标已有颜色 × 1，即加法混合。用于 Bloom 的 Combine Pass，将模糊后的亮部直接加到已有的场景颜色上，实现 `scene + bloom` 的叠加效果，而不需要在 Shader 中手动采样两张纹理相加。

**所在层级：**

ShaderLab Pass 内部，`HLSLPROGRAM` 之前。

**常见坑：**

- 如果渲染目标通过 `SetRenderAttachment` 声明为 `AccessFlags.Write`，Render Graph 可能跳过 Load 操作（已有颜色被丢弃为 DontCare），导致混合结果变成 `bloom + 0 = bloom`。必须使用 `AccessFlags.ReadWrite` 确保已有颜色被加载。
- `Blend One One` 不需要在 Shader 代码中手动做 `scene + bloom`；片元着色器只需输出 bloom 颜色，GPU 自动完成叠加。

### 具体非函数名：

`CBUFFER_START(UnityPerMaterial) / CBUFFER_END`

**在哪个效果中记录：**

高斯模糊后处理

**形式：**

```hlsl
CBUFFER_START(UnityPerMaterial)
    float _BlurSpread;
CBUFFER_END
```

**作用：**

在 HLSL 中声明一个全局常量缓冲区（Constant Buffer）。当在 C# 中使用 `material.SetFloat("_BlurSpread", value)` 时，Unity 会自动把值送入 GPU 这一块名为 `UnityPerMaterial` 的小容量高速常量内存区，实现 CPU 向特定材质 Shader 变量的数据传递。

**所在层级：**

在 Shader 文件的 SubShader 内的 `HLSLINCLUDE` 声明块中。

**常见坑：**

- 在 SRP（URP/HDRP）中，凡是在材质属性（Properties）中声明并在 C# 中被修改的自定义变量，都**必须**包裹在此常量缓冲区内，否则会破坏 URP 的 SRP Batcher 优化导致合批失效。
- 纹理对象（如 `TEXTURE2D`）不能放在此 Block 内部，否则会引发 Shader 编译报错。
- 常量缓冲区是 GPU 只读的，无法在 Shader 运行中修改它的数值再传回 CPU。
